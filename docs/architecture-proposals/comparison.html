AWS + GCP 3Tier 고가용성 아키텍처: 3개 안 비교

2026-11-06 · 원문: docs/architecture-proposals/{claude,codex,antigravity}.md

결론: Claude 안을 뼈대로, Codex의 대체 경로와 Antigravity의 스키마 관리를 더하는 조합을 추천합니다.
세 안의 기본 구조는 같습니다. 가장 큰 차이는 AWS가 죽었을 때 운영 도구가 살아남는지와 전환을 얼마나 자동화하는지입니다.
참고: 이 비교는 Claude인 제가 작성했으므로 Claude 안에 유리하게 기울 수 있습니다. 아래 판단 근거를 직접 확인해 주세요.

1. 세 안이 공통으로 고른 구조

GitHub Actions(CI) · ArgoCD(CD) · Terraform + Ansible · Prometheus + Grafana

셋 다 액티브-액티브, 서비스 메시, 분산 DB를 뺐고, DB 승격은 자동화하지 않습니다. 스플릿 브레인으로 중복 판매가 생길 위험 때문입니다.

이 일치를 독립적인 검증으로 보지는 마세요. 세 워커 모두 제가 쓴 같은 지시문("과설계는 감점")을 받았고, 4인 팀·서울-서울 리전·예약 서비스라는 가정까지 같습니다. 서울-서울 구성은 도시 단위 재해를 막지 못합니다.

4. 안별 평가

Claude: 2단계 전환

강점
  • 읽기는 자동, 쓰기는 승인 후 복구해 자동화 경계의 근거가 분명함
  • 복제 지연을 직접 재는 상황판, 복귀 차단 등 실패 지점을 가장 많이 다룸
  • 검증한 사실과 미검증 항목을 부록으로 구분함
약점
  • 구현량과 비용이 가장 큼
  • DMS는 마이그레이션 도구라 DR 장기 사용은 비권장 용도임
  • Route 53 자체는 AWS 의존임
  • 매일 terraform destroy는 재구성 시간 부담이 큼 (제 판단)
  • 시연 스크립트의 replica 0과 보안 그룹 변경은 ArgoCD와 컨트롤러가 되돌릴 수 있어 리허설로 확인 필요 (제 판단)

Codex: 최소 구성

강점
  • 6주 안에 끝낼 가능성이 가장 높음
  • 복제 실패 시 백업 복원으로 바꾸는 대체 경로가 명확함
  • 과장 없이 한계를 설명함
약점
  • 전환이 전부 수동이라 RTO가 길고 시연 효과가 약함
  • "AWS 쓰기 차단을 확인 못 하면 GCP 쓰기를 열지 않는다"는 규칙은 AWS가 완전히 죽으면 전환을 막을 수 있어 예외 절차가 필요함
  • Ansible 비중이 작아 평가 항목이라면 불리함
  • VPN과 LB 등을 합쳐 $100인 항목은 낮아 보임

Antigravity: 시연 중심

강점
  • 월 비용이 가장 낮고 절감 방법이 구체적임
  • Cloudflare로 DNS의 AWS 의존을 없앰
  • Flyway 스키마 관리와 15분 시연 타임라인이 실용적임
약점
  • 시연 중 EKS 노드를 정지하면, EKS에 있는 Grafana와 Alertmanager도 함께 멈춰 핵심 화면이 사라짐
  • "무중단"을 내세우지만 수동 승격이 있어 실제로는 무중단이 아님
  • 승격 후 시퀀스 보정과 Redis 좌석 선점 유실을 다루지 않음
  • Spot 노드에 의존해 전환 순간의 위험이 큼

6. 추천 조합

  1. Claude 안에서: 2단계 전환, 클러스터별 독립 ArgoCD, GKE의 Grafana, 복제 지연 상황판, 읽기 전용 모드, S3 + GCS state 분리, Ansible failover 플레이북.
  2. Codex 안에서: 2주차 복제 PoC 실패 시 백업 복원으로 바꾸는 기준, 양쪽 레지스트리 동일 digest 게시.
  3. Antigravity 안에서: Flyway로 양쪽 스키마 관리, 15분 시연 타임라인, 단일 NAT 등 개발기 절감. Cloudflare는 요금과 주기를 확인한 뒤 Route 53 약점의 대안으로 검토.
  4. 새로 수정: 데모 주간 전까지 VPN은 2터널로 유지하고, 매일 전체 삭제 대신 노드 축소와 부분 삭제를 먼저 씁니다. 일정이 밀리면 Rollouts부터 롤링 + Git revert로 줄입니다.
첫 검증 과제 (2주차까지): RDS → VPN → Cloud SQL 복제와 승격을 실제로 돌려 봅니다. Claude와 Codex가 이 구간을 가장 큰 위험으로 꼽았고, Antigravity도 관련 구성을 미검증으로 남겼습니다. 여기서 복제 방식을 확정합니다.
